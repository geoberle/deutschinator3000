# Deutschinator 3000

German grammar trainer for ADHD-friendly learning. Static SPA, no backend.

## Deploy

- Hosted on GitHub Pages: https://geoberle.github.io/deutschinator3000/
- After meaningful changes to `app.js`, `style.css`, or exercise files: bump `?v=N` in `index.html` and push
- `index.html` references `style.css?v=N` and `app.js?v=N` — increment N on deploy to bust browser caches
