# Deutschinator 3000

Eine Web-App zum Trainieren der deutschen Grammatik, zugeschnitten auf Schüler der Unterstufe (10-14 Jahre, 5.-8. Klasse).

## Themen

- **Zeitformen** — Präsens, Präteritum, Perfekt, Plusquamperfekt, Futur I & II
- **Wortarten** — Nomen, Verben, Adjektive, Pronomen, Adverbien, Konjunktionen, Präpositionen, Artikel
- **Satzglieder** — Subjekt, Prädikat, Objekte, adverbiale Bestimmungen
- **Groß- und Kleinschreibung** — Substantivierungen, Anredepronomen, Satzanfänge
- **s-Schreibung** — s, ss, ß nach den aktuellen Rechtschreibregeln
- **Satzzeichen** — Kommasetzung, direkte Rede, Doppelpunkt, Semikolon

## Funktionen

- Interaktive Übungen mit sofortigem Feedback
- Übungen nach Thema und Schwierigkeitsgrad filterbar
- Fortschrittsanzeige pro Themengebiet
