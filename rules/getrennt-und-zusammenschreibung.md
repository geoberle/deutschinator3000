# Getrennt- und Zusammenschreibung

## 1) Nomen + Verb

**Nomen + Verb werden getrennt geschrieben.**

z. B.:
- Ski fahren
- Fenster putzen
- Radio hören
- Walzer tanzen
- Schlange stehen

### Ausnahme: Nominalisierung

Wird die Verbindung nominalisiert, schreibt man sie zusammen.

z. B.:
- Das **Skifahren** macht Spaß.
- Beim **Schlangestehen** tun mir gleich die Füße weh.
- Er hat mir das **Radfahren** beigebracht.


## 2) Verb + Verb

**Zwei Verben hintereinander werden getrennt geschrieben.**

z. B.:
- schreiben lernen
- spazieren gehen
- liegen bleiben

### Ausnahme

Wenn sich durch die Zusammenschreibung eine **neue bzw. übertragene Bedeutung** ergibt, wird zusammengeschrieben.

z. B.:
- **sitzen bleiben** = auf einem Stuhl
- **sitzenbleiben** = die Klasse wiederholen


## 3) Weitere Beispiele

Manchmal entscheidet die **Bedeutung**, ob getrennt oder zusammengeschrieben wird.

- **fest halten** = etwas kräftig halten
- **festhalten** = am Weglaufen hindern / etwas aufschreiben

- **leicht fallen** = ohne schweren Aufprall
- **schwerfallen** = mit Mühe

> Ihm ist es sichtlich **schwergefallen**, vor anderen zu sprechen.


## 4) Adjektiv + Verb

**Adjektiv + Verb wird getrennt geschrieben, wenn das Adjektiv gesteigert oder erweitert werden kann.**

z. B.:
- klein schneiden → kleiner schneiden
- laut lachen → lauter lachen
- schön schreiben → schöner schreiben

**Ist das Adjektiv nicht steigerbar, wird zusammengeschrieben.**

z. B.:
- freisprechen
- krankschreiben

### Achtung!

Wenn das Adjektiv das **Ergebnis einer Handlung** bezeichnet, kann getrennt **oder** zusammengeschrieben werden.

z. B.:
- klein schneiden / kleinschneiden
- kaputt machen / kaputtmachen


## 5) Verbindungen mit „sein“

**Verbindungen mit „sein“ werden immer getrennt geschrieben.**

z. B.:
- da sein
- zusammen sein
- vorbei sein
